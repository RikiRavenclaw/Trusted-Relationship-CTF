# Hogwarts CTF Website

## Files
- `index.html` — About Hogwarts homepage
- `houses.html` — The Four Houses
- `classes.html` — Classes and Courses
- `staff.html` — Staff Directory
- `login.html` — Student Login (visual demo only)
- `transportation.html` — Transportation information
- `style.css` — Shared site styling
- `script.js` — Shared navigation and demo login behavior

## Use
Keep all files in the same folder. Open `index.html` to preview locally, or upload the files to the same GitHub Pages directory.

The Transportation page currently links to `https://example.com`. Replace that URL with the URL of your Hogwarts Express CTF website.

The student login is intentionally nonfunctional: it does not authenticate users or store passwords. GitHub Pages is static hosting, so do not put real credentials or secrets in these files.
