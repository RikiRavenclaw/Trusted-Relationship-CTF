HOGWARTS EXPRESS WEBSITE

Files:
- departure.html          Public departure information page
- boarding.html           Student boarding instructions
- prefects.html           Instructions for prefects
- employee-login.html     Employee login page (visual CTF simulation)
- employee-dashboard.html Separate dashboard page, not linked in the navigation
- style.css               Shared styling for every page
- script.js               Builds the shared header and footer on each page

HOW TO USE
1. Extract the hogwarts-express folder.
2. Put the folder in your GitHub repository.
3. Keep all files together in the same folder.
4. Open departure.html to view the site locally, or publish the folder with GitHub Pages.

SHARED HEADER
The header is generated by script.js. Each page has:
  <body data-page="page-name">
  <header id="site-header" class="site-header"></header>

The navigation links point to separate HTML files. The current page is highlighted automatically.

CTF NOTE
The employee dashboard is intentionally not linked in the public navigation, but it can be opened directly at:
  employee-dashboard.html

The employee login form is a front-end demonstration only. It redirects to the dashboard and does not verify credentials. Static HTML/CSS/JavaScript on GitHub Pages cannot provide real authentication or protect private information. Use fictional data only. The intentionally exposed dashboard demonstrates missing access control; it is not a secure login implementation.
